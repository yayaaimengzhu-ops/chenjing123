# 直播间 / 短视频评论屏蔽词

依据：《星光直播违规解密》资料 + 10-10～10-12 违规相关课程逐字稿，另按“直播/IP 知识付费培训”行业加了扩展词。

## 文件说明

| 文件 | 用途 |
|---|---|
| `1_核心版_一行一个.txt` | **直接上传用**（约 300 个），适合 抖音、视频号 |
| `2_核心版_逗号分隔.txt` | 同上，用于只能粘贴一整段的输入框 |
| `3_完整版含行业扩展_一行一个.txt` | 核心版 + 医美 / 留学 / 招商 / 视频号加强 |
| `4_完整版含行业扩展_逗号分隔.txt` | 同上，逗号分隔 |
| `分类对照表.md` | 每个词属于哪一类、为什么要屏蔽，方便自己增删 |

## 上传前必看

1. **条数上限**：各平台屏蔽词的条数上限不一样，而且会调整。超了就从文件**顶部开始传**：文件按危险程度排好了，引流和涉政在最前面。
2. **按平台删一个词**：在视频号上传时删掉“视频号”，在抖音上传时删掉“抖音号”，免得误伤正常提到本平台的评论。
3. **包含匹配**：平台一般是“包含即屏蔽”，所以文件已去掉被短词覆盖的长词，比如有了“微信”就不再放“加微信”。坏处是可能误伤，比如“假的”也会命中“放假的”。
4. **故意没有屏蔽的词**：没屏蔽“多少钱”“怎么买”“进群”“粉丝群”“涨粉”“起号”“限流”“下线”。这些是真实学员的成交信号或正常提问，屏蔽了会伤转化。
5. **“退款 / 退钱 / 投诉”已屏蔽**：评论区看不到，不等于问题没了。要安排客服每天去后台看被屏蔽的评论并跟进处理，否则会升级成平台投诉。
6. **屏蔽词只管观众的评论**：主播口播、贴片、标题、简介、连麦的人说的话，照样会被审核。主播自己也要避开同一批词。
7. **变体**：恶意评论会用拼音、谐音、空格、emoji 绕开。直播后复盘被屏蔽和没被屏蔽的评论，把新出现的变体补进 `分类对照表.md` 对应的分类里。
