# 防限流 / 防封号 自查清单

> 结论先说：**评论屏蔽词只能管住 12 个审核范围里的 1 个（评论区），而且只能管住其中“写明了的词”。**
> 真正导致封号、限流的大头，来自主播本人的口播、文字类物料、连麦、私信 / 客服和账号设置。屏蔽词要和下面这张清单一起用。

## 一、屏蔽词管得到 / 管不到什么

| 能管住 | 管不住 |
|---|---|
| 观众评论里**原样出现**的违禁词，比如“vx”“翻墙”“骗子” | 拼音、谐音、拆字、空格、emoji、图片评论，以及新出现的变体（“八加一”“打动物”这类暗语） |
| 同行、黑粉在评论区刷屏、带节奏 | **语境识别**：每个词都不违规，但连起来像在讲股票、讲副业收益 |
| 评论区高频出现敏感话题（比如跨境直播间老有人问翻墙） | **人工巡查**：千人以上的直播间有巡管，人一看就懂 |
| | **主播自己说的话**、贴片、标题、封面、简介、昵称 |
| | **连麦的人说的话**（课上的例子：“新疆炒米粉”“习近平”“省委书记”） |
| | 私信、小店 / 飞鸽客服里发的微信号 |
| | 同行有组织的**恶意举报**（课上说两块钱就能买一次举报） |

> 还有一点无法确认：评论被屏蔽后，平台审核系统是否仍会把它算进“语境”。各平台没有公开这个规则，不要以为屏蔽了就绝对安全。

## 二、12 个审核范围逐项自查（开播前过一遍）

| # | 范围 | 自查要点 | 风险 |
|---|---|---|---|
| 1 | **头像昵称** | 不带“易经、算命、风水、财富、搞钱”等敏感字；不带微信号、手机号 | 高，长期没流量先查这个 |
| 2 | **个人简介** | 不放微信 / 手机号（官方只放开了邮箱）；不写“月入 / 赚到第一个一千万”这类数字 | 高 |
| 3 | **直播封面** | 文字越少越好；人物不露纹身、不暴露；不放二维码 | 中高，属于“人赃并获” |
| 4 | **直播标题 / 主题** | 不写“财商、理财、普通人如何赚到 100 万、副业变现” | 高，文字类最容易被抓 |
| 5 | **直播贴片** | 第一行写人设、第二行写人群痛点；不写数字、收益、保证；不放二维码（挂车时） | 高，长期限流常见原因 |
| 6 | **直播话术** | 背熟违禁词手册；不说数字、收益、承诺、永久、终身；不说其他平台名称加变现案例；不说领导人和机关名称 | 最高，弹窗主要来源 |
| 7 | **行为举止** | 不抽烟、不喝酒、不大声嘶吼；不对官方骂人、狡辩 | 中 |
| 8 | **直播着装** | 不赤膊、不穿睡衣、不暴露；不穿制服或佩戴有特殊含义的服饰 | 中 |
| 9 | **直播背景 / 画风** | 不在寺庙、军事场所前直播；背景音乐不用佛教音乐；画面不出现二维码、条形码、其他商品 | 中 |
| 10 | **连麦内容** | 连麦前先让对方打字说清行业；对方说错话**马上纠正**：“官方大大，连麦的朋友不懂规则，这个不能说哈”；不连陌生人 | **高，屏蔽词完全管不到** |
| 11 | **评论区** | 上传屏蔽词；**安排场控实时删评论、拉黑**；不在评论区回复引流内容 | 中，屏蔽词主要解决这一项 |
| 12 | **短视频（会连带影响直播）** | 字幕不打敏感字；不发“几月几号线下课”的硬广；有风险的视频**不投流、不加热** | 高，短视频违规会让直播间也限流 |

## 三、屏蔽词以外必须同时做的事

1. **私信 / 飞鸽客服**：所有自动回复和快捷短语里都不出现微信号、手机号。客服话术统一成“老师待会联系你”。课上讲过，这一项被抓几乎救不回来。
2. **挂车 / 挂码二选一**：挂了小黄车就不放企业微信二维码，放码就不挂车。两样都上，大概率会被处罚。
3. **场控（管理员）**：至少 1 人盯评论区，看到屏蔽词没拦住的变体就删评论、拉黑。直播结束后把这些新变体补进屏蔽词表。
4. **投流测试**：每场投 100 元左右，看会不会出现“当前内容不适合加热”或“投放熔断”，以此判断有没有被隐形限流。
5. **看流速图**：流速断崖下跌的时间点，往前倒查 3 分钟内的口播、连麦和评论。
6. **违规后**：先排查清楚原因再复播（复播太早会加重处罚）；不要随便点“无帮助”；申诉只有一次机会，材料准备齐了再提交。
7. **防举报**：不在直播里得罪同行，不点名、不拉踩；自己也不去举报别人。
8. **盯热点**：出了大的社会案件（诈骗、收割老年人等）之后，平台会对相关话术集中严打。这段时间要主动收紧，比如少讲“中老年创业、宝妈副业”。

## 四、哪些词屏蔽了也没用，主播自己要避开

下面这些词，**最终是主播自己说出来才最危险**，屏蔽词管不了：

- 数字和收益：多少万、多少钱、回报、利润、毛利、现金流、百分之多少
- 结果保证：包学包会、学不会退款、一定能考到 7 分、永久有效、终身回看（改成“2 年内有效”）
- 人群标签：普通人副业、宝妈宝爸、中老年创业
- 没挂车时提课程名、客单价；“最后一单”“最后 5 分钟”但库存充足
- “线下课”改说“面授 / 面对面”；“招商加盟”改说“扩店 / 盟商 / 千城万店”
- 领导人名字（包括昵称、谐音）、机关名称、新疆、西藏、台湾；香港、澳门必须说“中国香港”“中国澳门”
