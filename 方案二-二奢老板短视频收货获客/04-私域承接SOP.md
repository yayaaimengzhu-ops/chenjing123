# 04 私域承接 SOP

出处简称见 [README](README.md)。本 SOP 按私域课（陈静团队销冠温娜的分享）裁剪成二奢老板版本。私域课的总口径是把 5 元客户"批量的转化成我们后端的一万两千八"，方案二对应的是把体检客户转化成 6980 陪跑营。

## 0. 两个原则

- **练判断力，不背话术**："我们公司我从来不培训任何话术"〔私域课 00:31:53〕。判断力指两件事：这个人是不是潜在客户；他的转化周期是今天、一周还是一个月〔私域课 00:32:53〕。
- **记框架，不记话术**："你要记住的是什么？是框架，不是话术"〔私域课 01:14:40〕。下面的话术都是示范，按老板的情况换说法。

## 1. 承接号

### 主副 IP〔私域课 00:06:51–00:08:45〕
| 号 | 人设 | 谁在用 | 负责什么 |
|---|---|---|---|
| 主 IP | 你本人（老板人设） | 你 + 助手 | 破冰、筛选、开口；一对一诊断由你本人做 |
| 副 IP | 收货操盘手 / 顾问（助手） | 助手 | 服务、答疑、跟进、收单 |

- 开口率的差距："你的开口率只有百分之三十，而我的开口率能做到百分之八十"〔私域课 00:06:51〕。所有承接号都用 IP 本人形象。
- 副 IP 必须懂业务。助手要先把你的收货方法学会，至少能看懂一个二奢账号的问题。
- 新手助手可以和你同时登录一个号（一个用平板，一个用手机），聊不动时你接手〔私域课 00:42:52〕。

### 承接号检查
- [ ] 头像、昵称和公域一致，公域人设和私域人设"强一致"
- [ ] 朋友圈没有"火热报名中"这类销售味很重的内容〔私域课 00:04:25〕
- [ ] 没有标注"办公时间"〔私域课 00:03:30〕
- [ ] 朋友圈里能看到：收货过程、门店日常、帮同行改号的过程（"不仅晒结果，我还会晒过程"〔私域课 01:00:25〕）
- [ ] 加好友后不第一时间发群二维码和海报，不群发"进群了吗"

## 3. 三段式成交〔私域课 00:10:44–00:13:28〕

1. **公开课前**：IP 号统一破冰、筛选、打标签，然后走十步谈单。被公域内容"做过功课"的"神仙客户"会在这一步直接下单。
2. **公开课中**：每期招生前做一场私域公开课（腾讯会议或私域直播），讲收货的底层逻辑和案例，统一成交。
3. **公开课后**：还犹豫的继续一对一，必要时打电话。私域课说"我们电话成交率至少是百分之八十"，电话放在最后打，不是一上来就挨个打。

- 错误示范：加微后第一时间拉群听课，不买就在群里发广告〔私域课 00:12:31〕。

## 4. 十步谈单（二奢老板版）

私域课称之为"十步谈单法"〔私域课 00:20:00〕，流程比市面上长，因为 5 元客户需求并不强。完整的十步名称在课件上，逐字稿里没有逐条念出来；下面按讲述顺序整理成 11 个动作，并改成二奢场景。

### ① 筛选
- 三个标准：**支付能力**（最重要）、**需求强弱**、**决策链条长短**〔私域课 00:26:42–00:28:07〕。
- 侧面了解：看他的朋友圈、账号、店铺位置和规模，不发"查户口式"的模板〔私域课 00:28:07〕。
- 只把时间花在"有需求、有支付能力"的潜在客户身上〔私域课 00:25:44〕。

### ② 破冰
- 标准：关系有没有递进、有没有多个来回、有没有把人聊开心。
- 找共同点：同乡、同行、同样的开店经历〔私域课 00:39:06〕。
- 不回复怎么办〔私域课 00:41:05〕：脸皮厚再问（"问了三遍……三遍人家才回"）；用福利钩子（公开课）；去他朋友圈评论；换个话题。
- 语音、表情、文字轮番用，一句一句聊，不发大段文字〔私域课 00:51:27–00:52:26〕。

> 【示范】看你朋友圈，你们店上个月收了一只【品类】，成色真好。你们一般是老客户拿来的，还是陌生人找上门的？

### ③ 给情绪价值
- 夸要具体，夸他最在意的点。夸老板：格局大、有眼光；结合业务细节夸〔私域课 00:48:33–00:50:28〕。
- 忌讳多次反问、质疑客户。

### ④ 发体检表
- 发《二奢门店收货体检表》（见 03）。

> 我们给老板做诊断之前，都会先填一张体检表。你填一下，我看完跟你约二十分钟，帮你把账号过一遍。

### ⑤ 挖需（20 分钟诊断里完成）
- 连环三问：现状和感受 → 原因 → 目标〔私域课 00:54:20〕。
- 讲不解决的坏处、解决后的好处。

### ⑥ 晒案例
- 选和他相似度最高、"能让他有胜负欲、有攀比心理的案例"〔私域课 00:57:42〕：门店老板讲门店案例，回收老板讲回收案例，最好同城或同等级城市。
- 不要晒和他无关的大案例："动不动就说雷军都下场做 IP 了，雷军关我毛事"〔私域课 00:57:13〕。
- 晒过程，不只晒结果〔私域课 01:00:25〕。私域里可以讲具体数字，但也只讲事实、不做承诺。
- 【待填：至少准备 3 个案例——门店 1 个、回收寄卖 1 个、线上 1 个。每个写清：之前什么情况、做了什么、过程截图、现在怎样】

### ⑦ 开药方
- "成交前只开药方，不要去给他治病……你收的五块钱是什么？是挂号费"〔私域课 01:05:05〕。只给思路、方向和好处。

### ⑧ 种草陪跑营
- 自己要对产品极度自信〔私域课 01:08:59〕。
- 海报要配得上高客单的质感〔私域课 01:07:02〕。
- **展示交付细节**：客户怕"关门放狗，刷 POS 机"〔私域课 01:08:00〕。把第一期的上课截图、批改记录、复盘会议截图整理成一份"交付长什么样"的图集。

### ⑨ 破卡点（三明治沟通法）
三层：先共情理解 → 再提出观点破卡点 → 最后塞案例给希望〔私域课 01:12:48〕。"那什么用户异议十大法则、十大破冰话术，那些东西没有一点用"，要自己按业务写〔私域课 01:14:40〕。

卡点分两类〔私域课 01:10:23–01:12:47〕：**认知卡点**（先解决）和**行动卡点**（没时间、没钱、要商量、担心没效果、担心没交付、担心没人管）。

### ⑩ 一对一跟进
- 潜在客户不群发〔私域课 01:18:25〕，个性化跟进。原话是"每一个客户都是我的自顶"〔私域课 01:19:23〕（"自顶"是"置顶"的转写）。
- 周期可能一个月到半年，大量客户是在这一步跟丢的。直播客资的成交周期大约一个月，"上个月的客资，这个月转化"〔私董会 00:25:57〕。

| 时间点 | 动作 |
|---|---|
| 诊断后当天 | 发诊断报告（见 03） |
| 第 2–3 天 | 发一个同类型案例的过程 |
| 第 5–7 天 | 邀请他听私域公开课 |
| 公开课后 | 未成交的打电话 |
| 之后每 1–2 周 | 朋友圈互动 + 一对一发他关心的内容 |

### ⑪ 收单
- 不要有收钱卡点："你收钱才是对他负责"〔私域课 01:21:17〕。
- 逼单放在最后一步。前面都做完了，这一步逼单"是帮客户做出正确的选择"〔私域课 01:22:15〕。
- 可以用真实的稀缺：每期限额、同城限一位（如果采用）。
