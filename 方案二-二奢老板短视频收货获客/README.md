## 逐字稿里的转写误识别（别当真）

### 你的《五天密训》
- **内容形式**：内心OS ← 内COS / 内型YS；偷窥视角 ← 头盔视角；vlog ← 伪log。
- **平台和功能**：抖加（DOU+）← 抖家；蓝V ← 蓝薇。
- **其他常见词**：观点类 ← 关联类；二奢 ← 二手车 / 20 号；比价 ← 比较。
- **金额和播放量常省掉"万"字**，例如"280 的播放量"应是 28 万。引用数字前要核对。
- **课上播放的案例视频**：Speaker 1 以外的说话人大多是案例视频，不是你本人的话。

### 陈晶老师课程

- 短视频阵地课里的"于姐是专业做二手奢侈品的"，原视频是"于姐专业做未来二手车的"〔短视频阵地课 00:56:01〕（"未来"即蔚来），老师复述时才被转成二手奢侈品〔短视频阵地课 00:57:31〕。那段改稿案例是二手车，不是二奢，本方案只借用它的结构。
- 排雷课里"拍二手奢侈品……号拍了一个多月就一万多"的说话人是做兽药的学员〔排雷课 00:40:43〕，"二手奢侈品"是热词误识别。
- 痛点课的"你有病，我有药，找病因，三不吃"〔痛点课 00:24:24〕，"三不吃"原文没有解释，按讲解内容对应的是"三步解药 + 当场见效"。
- 投流实操标题里有"巨量千川"，正文只讲了视频号加热，没有抖音千川/DOU+ 的操作。
