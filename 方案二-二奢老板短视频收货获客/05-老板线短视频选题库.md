# 05 老板线短视频选题库

出处简称见 [README](README.md)：
- 〔D1 时间戳〕到〔D5 时间戳〕指你的《五天密训》逐字稿；其余简称是陈晶老师课程。
- 这份选题库是给**你自己的账号**用的，看的人是二奢老板。你在密训里教老板拍给 C 端客户看的选题，属于陪跑营的交付内容，不放在这里。

## 0. 先记住四件事

1. **选题要预设看的人是老板**，不是卖家，也不是店员。
   - 老师的例子："客户嫌贵怎么回"吸引来的是销售，"怎么判断一个人他具备成为销售管理者"吸引来的是老板〔产品课 00:30:54〕。
   - "拍了一堆成交话题，结果呢来的全是销售，都不是老板"〔短视频阵地课 00:14:20〕。
   - 用你自己的话说，就是"先有人群，人群之后才有选题"〔D1 00:09:00〕。
2. **选题决定 80%**："一个选题是决定了流量的 80%，没有之一"〔D1 00:13:52〕。下面每条都标了用的是哪个爆款元素。
3. **内容三方面都要有**：行业知识、你的观点、成交类内容（展示你的服务），"也不要单独做某一项"〔D5 00:00:00〕。
4. **好视频的标准**："客户看五条短视频就想买单"〔短视频阵地课 00:05:31〕。

## 3. 你自己的两个脚本结构

原来借用的"于姐改稿"是二手车案例，现在换成你密训里讲的结构。

### 个人故事：钩子 → 背景 → 低谷 → 转折逆袭 → 成功〔D4 00:53:31〕
- **核心是"感悟"**："如果一个事情，对你没有任何触动……它不是一个好故事"〔D4 00:41:32〕。
- **拍法**：一小段一小段拍，不需要一气呵成。
- **红线**："可以渲染，但是不能说假话"〔D4 00:37:04〕。

**示范骨架**：以选题 16、17 为例。【细节必须换成你的真实经历】

> **钩子**：我第一条短视频，从想拍到发出来，整整拖了两个月。
>
> **背景**：我做鉴定讲师很多年，讲课、看货都不怕，可一对着镜头就不会说话。
>
> **低谷**：【待填：那两个月里具体的一件事——比如录了几十遍删掉、怕被亲戚看到】
>
> **转折**：【待填：是什么让你终于点了发布——比如一抄二改、先做先发】
>
> **成功**：后来我自己把号做起来了，现在还带着一批二奢老板一起拍。
>
> **感悟**：【待填：一句你自己的话，比如"想多了都是问题，做多了都答案"〔D5 02:06:33〕】

### vlog：六脉神剑〔D3 01:01:17〕
- **结构**：起因 / 钩子 → 关键步骤 1 → 2 → 3 → 4 → 展示成果。
- **最重要的是第一步**："六脉神剑的第一个第一个最重要点就是引发大家的好奇，也就是好的开篇"〔D4 00:09:04〕。

**示范骨架**：给自己的号拍"帮一个老板改号"的 vlog。【初稿】

| 步骤 | 内容 |
|---|---|
| 钩子 | 一个老板拍了三个月，粉丝里八成是中老年 |
| 步骤 1 | 打开他的主页，看五件套 |
| 步骤 2 | 看最近 9 条：全是段子和上新 |
| 步骤 3 | 在白板上画三角，圈出他缺的角 |
| 步骤 4 | 当场改一个选题和一个开头 |
| 成果 | 他第二天按新选题拍的那条视频 |

### 观点类：七条原则里最常用的两条〔D4 01:37:28〕
- **一个视频只站一方**。你的号站在"想把店做好的二奢老板"这一方。
- **永远不站品牌方或商家那一边**。对你的号来说，就是不站平台、不站代运营公司。

## 4. 结尾动作
- **可以用**：
  - "预约我的直播间"
  - "评论区告诉我你是做门店还是回收的"
  - "评论区打 1、2、3，告诉我你缺哪个角"
- **不要用**："领资料"〔短视频阵地课 01:05:43〕，以及"加微信""私信我""到主页来找我"〔D5 00:30:29〕。

## 5. 场景
- **在店里拍**，让人一看画面就知道你是做二奢的，不要用"大白墙"〔短视频阵地课 00:11:21〕。
- **构图**：眼睛和眉毛放在画面上三分之一处〔D1 01:54:21〕。
- **少用炸裂音乐、频繁推拉摇移**。老师点评过实体老板爱用这些手段增加停留，但"没有让出任何让你想买单的冲动"〔短视频阵地课 00:57:31〕。

## 6. 创作流程：用你自己的单条视频路径〔D5 02:00:11〕
1. **先找人群**：这里是二奢老板。
2. **定选题**：从素材库来——备忘录、语音笔记、抖音收藏夹〔D4 00:00:02〕。
3. **用八大爆款元素优化选题**：成本、人群、奇葩、最差、反差、怀旧、荷尔蒙、头牌。
4. **定呈现形式和结构**：口播、内心 OS、偷窥视角、打枪、一人分饰两角、vlog。
5. **填内容**：AI 写前 80%，最后两步你自己改，去掉 AI 味〔D5 00:04:48〕。
6. **优化开篇**：五类句式，否定句更强。
7. **拍摄、剪辑、发布**。
8. **用成交三角模型验证**：有没有流量、人设、产品，人群准不准。
