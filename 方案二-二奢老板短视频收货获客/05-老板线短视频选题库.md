# 05 老板线短视频选题库

出处简称见 [README](README.md)。

## 0. 先记住三件事

1. **选题要预设看的人是老板，不是卖家，也不是店员。** 老师的例子："客户嫌贵怎么回"吸引来的是销售，"怎么判断一个人他具备成为销售管理者"吸引来的是老板〔产品课 00:30:54〕；"拍了一堆成交话题，结果呢来的全是销售，都不是老板"〔短视频阵地课 00:14:20〕。所以下面的选题讲的都是"老板怎么用短视频收到货"，不是直接对卖家喊"高价回收"。
2. **每条都植入人设、人群、案例**："一条优质的视频……满足三个点：有人设，有人群，有案例的植入"〔短视频阵地课 00:20:18〕。
3. **好视频的标准**："客户看五条短视频就想买单"〔短视频阵地课 00:05:31〕。

## 3. 人设兜底模板（改自"于姐"改稿案例）

原案例是蔚来二手车，不是二奢，这里只借它的结构〔短视频阵地课 00:58:03–01:04:16〕。老师的改法："干货视频要植入人设和案例。与其植入案例，不如植入人设，或者说案例型的人设"；"我把一个人设的售后点放在了干货里面"；"越是售后，它是最体现一个老板他的格局的"。

### 结构
1. **开头**：一个反常识的结论 + 你的身份背书（不讲收益数字）。
2. **三个干货**：每个都是老板（或卖家）常忽略的坑。
3. **在第三个干货里植入一个真实的兜底故事**：你的客户 / 卖家遇到了问题，你是怎么解决、承担了什么。
4. **结尾**：一句价值观 + 指令动作（预约直播 / 评论区留言）。

### 示范稿【结构示意，故事必须换成你的真实经历】

> 开二奢店的老板，很多人是收完货才发现自己亏了。我开店【待填：几年】了，也踩过这个坑。今天说三个收货时容易忽略的地方。
>
> 第一，【待填：坑一】。
>
> 第二，【待填：坑二】。
>
> 第三，【待填：坑三】。说到这个，我想起【待填：一个真实的兜底故事——卖家或客户遇到了什么问题，你第一时间做了什么、承担了什么】。
>
> 做二奢，货是底气，信任是招牌。你想知道怎么让卖家主动找上你，预约我的直播间，我当场帮你看账号。

## 4. 结尾动作

- 可以用："预约我的直播间""评论区告诉我你是做门店还是回收的""评论区打'收货'，我挑几个号直播里看"。
- 不要用："领资料""加微信""私信我"〔短视频阵地课 01:05:43〕〔违规课 00:19:24〕。

## 5. 场景

- 在店里拍，让人一看画面就知道你是做二奢的。不要用"大白墙"〔短视频阵地课 00:11:21〕。
- 少用炸裂音乐、频繁推拉摇移。老师点评实体老板爱用这些手段增加停留，但"没有让出任何让你想买单的冲动"〔短视频阵地课 00:57:31〕。

## 6. 创作流程〔短视频阵地课 01:07:10–01:18:41〕

1. 先列提纲。
2. 用语音口述 5–10 分钟（例如用 Get 笔记），平时每天储备 3–5 条灵感。
3. 搜对标爆款，提取逐字稿。
4. 把自己的口播稿和约 3 篇对标稿一起交给 AI："咱们用的是别人的爆款骨架……里面的血肉都是咱们自己的语料"〔短视频阵地课 01:09:12〕。
5. 自己润色后再拍，不直接用 AI 稿。
6. 用提词器，或者三句三句分段拍。
